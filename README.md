Deckly — Sistema Web

O Deckly é um projeto de sistema web para gerenciamento e comercialização de produtos colecionáveis, desenvolvido para uma loja de cartas colecionáveis.

Funcionalidades
Vitrine de produtos, com pesquisa, filtros e paginação.
Painel administrativo.
Gerenciamento de produtos, categorias e marcas.
Cadastro e gerenciamento de clientes e funcionários.
Controle de estoque e preços promocionais.
Integração com banco de dados MySQL.

Banco de dados

O arquivo SQL de demonstração está disponível na pasta database. Importe o banco de dados no MySQL e configure a conexão no arquivo correspondente antes de executar o projeto.

Como executar
Instale um ambiente local com PHP e MySQL (por exemplo, o XAMPP).
Clone este repositório e coloque a pasta do projeto no diretório do servidor (no XAMPP, a pasta htdocs).
Importe o arquivo SQL da pasta database no MySQL.
Configure a conexão com o banco de dados (servidor, usuário, senha e nome do banco) no arquivo de conexão do projeto.
Inicie o Apache e o MySQL e acesse o projeto pelo navegador, em http://localhost/ seguido do nome da pasta do projeto.
Observação

Este projeto utiliza dados de demonstração. Configure o ambiente local antes de executar o sistema.

Faz parte do ecossistema Deckly, que também possui uma versão desktop.
